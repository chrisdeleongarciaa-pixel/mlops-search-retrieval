# 0003 · Citas y entrega de respuestas

**Estado** · Pendiente.

El contrato público debe elegir entre liberar contenido tras validarlo o entregar eventos provisionales con una confirmación terminal explícita. Define qué hace el cliente cuando hay citas inválidas, cancelación o fallo de validación. Evalúa por separado si una referencia resuelve a un fragmento del contexto efectivo y si ese fragmento respalda la afirmación.

**Evidencia para cerrar.** Un identificador inventado, un bloque eliminado por truncamiento y un fragmento real sin respaldo para la afirmación producen resultados distinguibles en el evaluador. Los eventos del cliente respetan la semántica adoptada incluso cuando la conexión se corta antes de la validación terminal.
