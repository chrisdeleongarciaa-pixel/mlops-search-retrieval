# Witness profile contracts

The archived candidate specification retains its original bytes and checksum. This document records the implemented boundaries and their observable guarantees. [Reference snapshot](../../engineering/reference/v1/CONTRATOS_Y_ENTORNO_REPRODUCIBLE_RETRIEVAL.md) · [Checksum](../../engineering/reference/v1/SHA256SUMS) · [Verification](../verification/witness-increments.md)

| ID | Caller obligation | Postcondition and invariant |
| --- | --- | --- |
| SE-01 | `EventSubmission.submit_event` receives authorized scope, v2 envelope and an upsert stream when applicable. Fields include `source_event_id`, `document_id`, `source_position`, `source_revision` and `operation`. An upsert adds `original_ref`, `original_version`, `original_size` and `original_sha256`. | Resolve source event ID within tenant and source before ordering. An equivalent retry returns the durable outcome. An already accepted position under a different ID records a stale outcome. Event, receipt and outbox share a transaction. The migration retains v1 receipts. |
| SE-02 | `replay_witness` receives a trusted manifest with unique contiguous cursors and a corpus matching its hash. | The manifest hash identifies the checkpoint. One durable decision advances one cursor. A gap, conflict or uncertain outcome stops advancement. Delivery cursor, event identity and source position are distinct. |
| SE-03 | After interruption, resend the same envelope and bytes. | Before commit, an unreferenced original may remain. After commit, retry recovers the same receipt and one logical event. |
| WP-01 | A worker holds a valid outbox lease, verifies the original and builds a UTF-8 fragment manifest with half-open byte ranges. | Reservation binds a projection ID to an immutable hash. Activation requires search visibility, a valid lease token, active generation and desired sequence. Withdrawal excludes prior publications even after another update is accepted. |
| WP-02 | Search receives the caller's authorized tenant and a positive budget. | Filter tenant, generation and eligible projections before limiting results. Revalidate and retry at most once on change. Context and cache reuse need a fresh authority read. The mutable witness defaults to at most 1,000 projections. |
| RB-01 | Exact retrieval and RRF receive compatible inputs and complete lists for one snapshot. | Missing eligible vectors fail exact retrieval. RRF preserves branch ranks and breaks score ties by ID. |
| DL-01–DL-07 | Transport supplies a principal-bound authority read. Private inference runs within the authorized boundary. Count tokens with the model's actual chat template. | Revalidate before context and before returning a complete private body. Citations identify effective-prompt fragments. Public delivery separates provisional tokens from a terminal event. Closing the stream closes the backend iterator and returns the admission slot. |

The local ACL policy grants access directly by principal and document. The operator classifies a private document before activation. Public search excludes classified documents. Classification and grant changes belong to the authorized PostgreSQL operator.
