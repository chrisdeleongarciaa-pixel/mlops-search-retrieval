# SciFact exact encoder comparison

This record uses 300 official test queries. `manifest.json` records the scores, vector spaces and encoding profiles. `per-query.json` retains individual metrics, `rankings.json.gz` holds ranked outputs and `SHA256SUMS` identifies those three artifacts.

The comparison holds corpus and queries fixed across the recorded CPU encoding profiles. ANN behavior and service latency use separate experiments. [Experiment record](../../../docs/experiment-record.md)
