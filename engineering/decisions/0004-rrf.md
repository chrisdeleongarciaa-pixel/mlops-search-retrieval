# 0004 · Hybrid RRF baseline

Keep independent complete lexical and dense lists for one eligible snapshot. Use 100 candidates per branch, equal weight, constant 60 and stable ID tie-breaking. Preserve rank and presence in each branch. Feature ranking over a previously truncated joint list constitutes a separate configuration.

A hand-calculated test and an independent replay of the eight paired builds reproduce both fusions. Gemma HNSW + BM25 improved Recall@100 and missed the NDCG@10 acceptance target. [Audit](../../docs/verification/scifact-stability.md)
